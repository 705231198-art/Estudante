🐛 Conflitos Identificados e Corrigidos

1. Conflito de localStorage Keys
CORRIGIDO
Problema: O auth.js armazenava com chaves diferentes do que membros.js esperava
auth.js: localStorage.setItem('ucm_token')
membros.js (antes): localStorage.getItem('token') ❌
membros.js (depois): localStorage.getItem('ucm_token') ✅
✓ Solução:
Atualizado carregarDadosUsuario() em membros.js para usar as 4 chaves corretas: ucm_token, ucm_estudante, ucm_remember, ucm_email_remember
2. Nome do Utilizador não Aparecia
CORRIGIDO
Problema: O header teria um espaço para o nome mas nunca era preenchido
<span id="userName">Carregando...</span> sempre ficava como "Carregando..."
✓ Solução:
Adicionado preenchimento do campo userName no método _configurarElementosDOM() com: this.estudante.nome
3. Dropdown Menu não Funciona
CORRIGIDO
Problema: O menu dropdown (Perfil, Configurações, Sair) não abria ao clicar
Não havia JavaScript para gerenciar o estado do dropdown
✓ Solução:
Implementado toggle de dropdown com event listeners no _configurarElementosDOM(). Menu abre/fecha ao clicar no botão e fecha ao clicar fora.
4. Falta de CSS do Header e Menu
CORRIGIDO
Problema: membros.css não tinha estilos para o header, menu de utilizador e dropdown
.membros-header { } (vazio)
.user-menu { } (vazio)
.dropdown-menu { } (vazio)
✓ Solução:
Adicionadas ~100 linhas de CSS com estilos profissionais para header, menu, dropdown, hover effects, e gradiente roxo
5. Altura do Container Incorreta
CORRIGIDO
Problema: Container usava 100vh causando overflow vertical
ANTES: min-height: 100vh ❌
DEPOIS: min-height: calc(100vh - 80px) ✅
✓ Solução:
Alterada altura para respeitar a altura do header (80px)
